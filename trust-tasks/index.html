RLTP Trust Task types

Private Trust Task types registered under https://real-life.org/trust-tasks/ by the Real Life Trust Protocol (ToIP DTGWG Trust Tasks 0.4 (draft), §6.5 private specifications).

Machine-readable registry: index.json — every type with its Type URI, payload-schema URL, defining section and SHA-256 digest. Each payload schema resolves as raw JSON at <Type URI>/schema.json.
